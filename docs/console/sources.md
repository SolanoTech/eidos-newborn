# Источники и уровни доверия

**Консоль администратора → Источники** — реестр систем, которые передают
данные в платформу. Понятия — [Источники, доверие и контракты](../concepts/sources-and-contracts.md).

## Список источников

| Колонка | Что показывает |
|---|---|
| Код | Уникальный код источника |
| Название | Человекочитаемое имя |
| Доверие | Уровень доверия из реестра |
| Токен | Начало и конец токена доступа |
| Статус | «активен» или «выключен» |

## Завести источник

1. Нажмите **Новый источник**.
2. Заполните:
    - **Код** — латиницей, без пробелов, например `bank-1`. Код станет именем
      источника во всех данных — не меняйте его после начала приёма;
    - **Уровень доверия** — от 1 до 10;
    - **Название**;
    - **Токен доступа** — нажмите **Сгенерировать**.
3. Нажмите **Сохранить**.

!!! warning "Обязательный шаг вне консоли"
    Источник из реестра ещё не принимается ядром: его нужно добавить в таблицу
    источников ядра с тем же кодом и уровнем доверия. Пока этого не сделано,
    данные источника уходят в очередь конфликтов с пометкой «unknown source».
    Инструкция — [Регистрация источника](../sources/registration.md#регистрация-в-ядре).

Подзаголовок экрана сообщает, что уровень доверия управляет приоритетом при
слиянии. В текущей версии на слияние влияет уровень, записанный в ядре, а
значение в консоли — справочное. Меняйте их вместе.

## Передать токен

Полный токен виден в окне источника (**Изменить**). Скопируйте его и
передайте интегратору по защищённому каналу. Токен хранится открыто, и его
видит любой пользователь консоли.

## Изменить источник

**Изменить** открывает то же окно. Что можно менять:

- **название** — в любой момент;
- **уровень доверия** — вместе с ядром, см.
  [Смена уровня доверия](../sources/registration.md#смена-уровня-доверия);
- **токен** — новый токен действует сразу, старый перестаёт приниматься; см.
  [Смена токена](../sources/registration.md#смена-токена);
- **признак «Источник активен»** — в текущей версии приём не останавливает.
  Чтобы приостановить источник, смените токен.

## Удалить источник

**Удалить** убирает источник из реестра. Источник, у которого есть
дата-контракт, в текущей версии удалить не получится — консоль сообщит
«Не удалось удалить источник». Подробнее —
[Удаление источника](../sources/registration.md#удаление-источника).
