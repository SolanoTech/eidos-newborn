# Вход, роли, навигация

В модуле две веб-консоли:

| Консоль | Для кого | Адрес на стенде |
|---|---|---|
| **Консоль администратора** | Администратор источников, дата-стюард | <http://localhost:8088> |
| **Фронт-офис** | Оператор, работающий с клиентами | <http://localhost:8089> |

## Вход

Консоли не имеют своей формы входа: при открытии браузер переходит на страницу
входа Keycloak, а после входа возвращается в консоль. На стенде заведён
пользователь `admin` с паролем `admin`; в рабочей установке учётные записи
создаёт администратор Keycloak — см. [Keycloak](../operations/keycloak.md).

- Консоль сама продлевает сессию, пока вы работаете.
- Сессия завершается после 30 минут бездействия — потребуется войти снова.
- Кнопка **Выйти** в правом верхнем углу завершает сессию в Keycloak.

Если после входа разделы показывают «Не удалось загрузить…», проверьте, что
платформа и Gravitee запущены, — см.
[Устранение неполадок](../operations/troubleshooting.md#консоль).

## Роли

В текущей версии одна роль — `ADMIN`. Она нужна для работы в обеих консолях и
даёт доступ ко всем функциям. Разделение на администратора источников и
дата-стюарда — организационное: руководство описывает задачи каждой роли, но
технически права одинаковы.

## Оформление

В правом верхнем углу — переключатель светлой и тёмной темы. Выбор
запоминается в браузере.

## Консоль администратора

Разделы в боковом меню:

| Группа | Раздел | Назначение | Состояние |
|---|---|---|---|
| — | Дашборд | Сводка платформы: записи, источники, конфликты, качество | Работает |
| Данные | Источники | Реестр источников | Работает |
| | Конструктор контракта | Правила преобразования данных источника | Работает |
| | Схема событий | — | Макет |
| | Kafka шлюза | Потребитель Kafka для физлиц | Работает |
| Качество | Очередь конфликтов | Разбор незавершённых записей | Работает |
| | Качество данных | Показатели качества | Показатели работают, инциденты — демо |
| Клиенты | Поиск Golden Records | Поиск и карточка физлица | Работает |
| Юридические лица | Поиск юрлиц | Поиск и карточка мерчанта | Работает |
| Управление | Согласия и контакты | — | Макет |
| | Интеграции и выгрузки | — | Макет |
| | Доступы и API | — | Макет |
| | Аудит-лог | Журнал действий | Работает, с ограничениями |
| | Приватность · GDPR | — | Макет |

Макеты показывают замысел будущих функций и не работают с данными.
