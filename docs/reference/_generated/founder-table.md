| Ключ | Значение | Ограничения | Описание |
|---|---|---|---|
| `uuid` | строка | до 64 символов | Идентификатор учредителя в источнике |
| `name` | строка | до 500 символов | Наименование или ФИО учредителя |
| `inn` | строка | `^\d{9}$` | ИНН учредителя-юрлица |
| `pinfl` | строка | `^\d{14}$` | ПИНФЛ учредителя-физлица |
| `sharePercent` | десятичное число | до 3 цифр в целой части и 2 в дробной | Доля в уставном фонде, % |
