# Перечисления

## Тип сущности

| Значение | Описание | Канал приёма |
|---|---|---|
| `PERSON` | Физическое лицо | `/api/v1/client-data`, топик физлиц |
| `LEGAL_ENTITY` | Юридическое лицо, мерчант | `/api/v1/legal-data`, топик юрлиц |

## Тип правила контракта

`STRING`, `DATE`, `INTEGER`, `BOOLEAN`, `GENDER`, `ARRAY`, `STRUCT` — см.
[Формат дата-контракта](contract-format.md#типы-правил).

## Логический тип поля Золотой записи

Из каталога полей (`GET /internal/api/v1/golden-record-fields`):

| Значение | Описание |
|---|---|
| `STRING` | Строка |
| `DATE` | Дата `yyyy-MM-dd` |
| `GENDER` | Пол: `M` или `F` |
| `BOOLEAN` | Логическое |
| `INTEGER` | Целое |
| `DECIMAL` | Десятичное число |
| `STRING_ARRAY` | Массив строк |
| `STRUCT_ARRAY` | Массив структур |

## Пол

| В API и контракте | В базе |
|---|---|
| `M` | `MALE` |
| `F` | `FEMALE` |

## Причина незавершённой записи

| Значение | Описание |
|---|---|
| `UNKNOWN_SOURCE` | Источника нет в таблице источников ядра |
| `GREY_ZONE_CONFLICT` | Расхождение с источником равного доверия |

## Решение по незавершённой записи

| Значение | Описание |
|---|---|
| `KEEP_CURRENT` | Оставить текущие значения |
| `ACCEPT_INCOMING` | Принять входящие значения |
| `REJECT` | Отклонить входящие данные |

## Типы согласий

| Имя (параметры запросов, база) | Код (тела запросов, события) | Описание | Срок по умолчанию |
|---|---|---|---|
| `PERSONAL_DATA` | `pd` | Обработка персональных данных | 180 дней |
| `BIO` | `bio` | Биометрия | 180 дней |
| `MARKETING_SMS` | `mk_sms` | Маркетинговые сообщения по SMS | 365 дней |
| `MARKETING_PUSH` | `mk_push` | Маркетинговые push-уведомления | 365 дней |
| `MARKETING_EMAIL` | `mk_email` | Маркетинговые письма | 365 дней |
| `PROFILING` | `profiling` | Профилирование | 365 дней |
| `THIRD_PARTY` | `third_party` | Передача третьим лицам | 365 дней |

## Тип события о согласии

| Значение | Описание |
|---|---|
| `new` | Согласие выдано |
| `expired` | У клиента не осталось действующего согласия этого типа |

## Категория записи аудит-лога

`gold`, `ok`, `warn`, `bad` — оформление записи в консоли.
