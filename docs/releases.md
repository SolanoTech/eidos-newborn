# Выпуски

## Текущее состояние

Пронумерованных выпусков пока нет. Документация описывает основные ветки
репозиториев на 28 сентября 2026 года — набор коммитов приведён на странице
[Совместимость версий](reference/compatibility.md).

Что входит в текущее состояние:

- приём карточек физлиц и юрлиц по REST и из Kafka, проверка по
  дата-контрактам, сохранение сырья;
- сопоставление по внешнему идентификатору и точным реквизитам, слияние по
  полям с учётом доверия, происхождение полей, архив версий;
- очередь ручного разбора конфликтов и данных от неизвестных источников;
- поиск физлиц и юрлиц, в том числе нечёткий поиск мерчантов по названию;
- сервис согласий с событиями `new` и `expired`, сверка согласия в ядре;
- слепой индекс для сопоставления и поиска по ПИНФЛ, ключи под защитой
  OpenBao; подготовленное хранилище токенов;
- консоль администратора и фронт-офис со входом через Keycloak;
- развёртывание через Docker Compose.

Известные ограничения — [Статус и ограничения](intro/status.md).

## Направления развития

Направления, отмеченные в коде и проектных материалах. Это не обязательства и
не сроки:

- обезличивание Золотых записей клиентов без действующего согласия на основе
  хранилища токенов;
- отдельный пользователь базы и, в перспективе, отдельный сервис для
  хранилища токенов;
- единый реестр источников для всех сервисов вместо отдельной таблицы ядра;
- передача токена пользователя от консолей до сервисов с проверкой прав в
  самих сервисах вместо общего административного токена;
- аудит административных операций через доменные события;
- миграции схемы на Flyway во всех сервисах.

## Формат примечаний к выпуску

С первым выпуском здесь появятся примечания в формате:

```markdown
## 1.0.0 — ГГГГ-ММ-ДД

### Новое
### Изменения
### Исправления
### Действия при обновлении
<!-- миграции, ручные SQL-команды, новые переменные, изменения API -->
### Версии модулей
<!-- репозиторий — тег -->
```

Раздел «Действия при обновлении» обязателен, если обновление требует чего-то
сверх пересборки, — см. [Обновление версии](operations/upgrade.md).
