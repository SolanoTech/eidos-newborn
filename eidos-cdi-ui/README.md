# eidos-cdi-ui

Консоли платформы: три приложения на общей дизайн-системе, собранные в одном
репозитории.

## Что внутри

**Консоль администратора** (`apps/admin`) — настройка платформы и разбор
спорных случаев: источники и их уровни доверия, конструктор дата-контрактов,
конфигурации потребителей Kafka, поиск по Золотым записям физлиц и мерчантов,
очередь конфликтов.

**Фронт-офис** (`apps/front-office`) — рабочее место оператора: поиск клиента,
карточка «Клиент 360» с происхождением каждого поля, история изменений, согласия,
связанные идентификаторы, карточка мерчанта.

**Маркетинг** (`apps/marketing`) — работа с сегментами и кампаниями.

Общие пакеты: `packages/ui-kit` — компоненты и дизайн-система, `packages/auth` —
вход через Keycloak, `packages/api-client` — обращения к API.

## Установка

```bash
docker compose up -d eidos-cdi-ui
```

Собирает консоль администратора и отдаёт её на порт **8088**. Фронт-офис
поднимается отдельным сервисом на **8089**:

```bash
docker compose up -d eidos-cdp-ui
```

Консоли обращаются к API через nginx: часть путей идёт в API-шлюз, часть — в
backend-for-frontend, поэтому для осмысленной работы нужен поднятый стенд.

Локальная разработка (нужен Node.js):

```bash
cd eidos-cdi-ui
npm install
npm run dev --workspace=apps/admin
npm run dev --workspace=apps/front-office
npm run dev --workspace=apps/marketing
```

Сборка и проверка типов:

```bash
npm run build --workspace=apps/admin
npx tsc --noEmit -p apps/admin/tsconfig.json
```

## Конфигурация

Адреса сервисов задаются не в коде приложения, а в `nginx.conf` каждой консоли:
там описано, какой путь куда проксируется. Параметры входа через Keycloak —
адрес сервера, realm и идентификатор клиента — задаются при сборке образа.

Оформление настраивается через CSS-переменные в `packages/ui-kit/src/styles.css`:
палитра, типографика, скругления и тени определены токенами и переключаются между
светлой и тёмной темой.

## Маршруты API

Собственных серверных эндпоинтов у консолей нет. Обращения распределяются так:

| Путь в консоли | Куда идёт |
|---|---|
| `/api/v1/admin/sources` | реестр источников через API-шлюз |
| `/api/v1/admin/golden-record-fields` | каталог полей Золотой записи |
| `/api/v1/admin/kafka-config` | конфигурации потребителей |
| `/api/v1/admin/golden-records` | Золотые записи физлиц |
| `/api/v1/admin/legal-records` | Золотые записи юрлиц |
| `/api/v1/admin/conflicts` | очередь конфликтов физлиц |
| `/api/v1/admin/conflicts-legal` | очередь конфликтов юрлиц |
| `/api/*` (остальное) | backend-for-frontend |
