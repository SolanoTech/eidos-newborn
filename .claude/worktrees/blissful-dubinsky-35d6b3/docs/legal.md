# Лицензия и товарный знак

## Лицензия

Исходный код и документация Eidos распространяются под
[Apache License 2.0](https://www.apache.org/licenses/LICENSE-2.0). Текст
лицензии — файл `LICENSE`, уведомления об авторских правах — файл `NOTICE`
в каждом репозитории.

Лицензия разрешает использовать, изменять и распространять код, в том числе в
коммерческих продуктах и услугах. Основные условия:

- сохраняйте текст лицензии и файл `NOTICE` в распространяемых копиях;
- отмечайте файлы, которые вы изменили;
- лицензия включает патентную лицензию от участников проекта;
- лицензия **не даёт прав на товарные знаки** (раздел 6).

Это краткое изложение, а не юридическая консультация: обязательную силу имеет
текст лицензии.

## Товарный знак

«Eidos», логотип Eidos и «SOLANOTECH» — товарные знаки LLC SOLANOTECH. Правила
их использования — файл `TRADEMARK.md`.

| Можно без разрешения | Нужно письменное разрешение |
|---|---|
| Честно описывать совместимость: «совместим с Eidos», «построен на Eidos», «плагин для Eidos» | Называть «Eidos» собственный продукт, сборку, форк или услугу, в том числе с добавлениями: «Eidos Pro», «Eidos Cloud» |
| Ссылаться на официальные репозитории и документацию | Использовать логотип как знак своего продукта или компании |
| Упоминать Eidos в статьях, докладах, учебных материалах | Регистрировать домены, аккаунты и названия, содержащие «Eidos» |
| | Создавать впечатление, что продукт выпущен или одобрен LLC SOLANOTECH |

**Форки** разрешены и приветствуются, но должны называться иначе и не
использовать логотип. Происхождение указывайте честно: «форк Eidos».

### Партнёрам

Партнёр может разворачивать платформу у заказчиков, дорабатывать её и
оказывать услуги на её основе в рамках Apache License 2.0. Если вы
распространяете изменённую сборку, назовите её по-своему или получите
разрешение на использование знака. Оформление консолей настраивается — см.
[Расширение платформы](development/extending.md#оформление-консолей).

## Сторонние компоненты

Поставка на Docker Compose использует компоненты с собственными лицензиями.
Условия некоторых из них ограничивают предоставление компонента третьим лицам
как сервиса — проверьте их, если вы предлагаете платформу как облачную
услугу.

| Компонент | Лицензия |
|---|---|
| Spring Boot, Spring Framework | Apache License 2.0 |
| Google Tink | Apache License 2.0 |
| Keycloak | Apache License 2.0 |
| Gravitee APIM, редакция Community | Apache License 2.0; функции Enterprise — по коммерческой лицензии Gravitee |
| OpenBao | Mozilla Public License 2.0 |
| PostgreSQL | PostgreSQL License |
| MongoDB Community Server | Server Side Public License v1 |
| Redpanda Community Edition | Business Source License 1.1 |
| Elasticsearch (стек Gravitee) | Elastic License 2.0, SSPL или AGPLv3 — в зависимости от версии и дистрибутива |
| nginx | BSD 2-Clause |
| Eclipse Temurin (JDK) | GPLv2 with Classpath Exception |
| Node.js (только сборка консолей) | MIT |

Лицензии сторонних компонентов меняются со временем — сверяйтесь с условиями
используемых версий. Kafka-совместимый брокер, PostgreSQL и MongoDB можно
заменить внешними экземплярами по вашему выбору — см.
[Требования](operations/requirements.md#компоненты-платформы).
