# Коды ответов и ошибки

## Формат

Все сервисы отвечают на ошибку одинаково:

```json
{"detail": "Человекочитаемое описание"}
```

Исключения:

- `eidos-cdi-ui-backend` на отсутствующий или неверный токен Keycloak отвечает
  `401` без тела;
- шлюз и `eidos-cdi-ui-backend` передают ответы нижележащих сервисов как есть.

## Коды

| Код | Значение в платформе |
|---|---|
| `200` | Успех |
| `201` | Создано: источник, правило контракта, согласие, связка внешнего идентификатора |
| `204` | Удалено |
| `400` | Неверный запрос: битое тело в `eidos-stage`, ошибки проверки тела административных API, занятые код или токен источника, неверный параметр в сервисе согласий |
| `401` | Нет или неверный токен: `X-Access-Token`, `X-Admin-Token` или токен Keycloak |
| `403` | Нет роли `ADMIN` (`eidos-cdi-ui-backend`) |
| `404` | Не найдено: запись, источник, связка, действующее согласие, контракт; в ядре — также неизвестный источник при приёме |
| `422` | Данные не прошли проверку или обработку: контракт, формат Золотой записи, отказ ядра, неверные данные запроса к ядру |
| `500` | Непредвиденная ошибка. В ядре и сервисе согласий — также отсутствующий обязательный параметр запроса и неверный формат параметра |

## Сообщения проверки Золотой записи

Ограничения полей сообщают так (свойство и текст):

| Ограничение | Сообщение |
|---|---|
| Обязательная строка | `<свойство> must not be blank` |
| Обязательное значение другого типа | `<свойство> must not be null` |
| Телефон | `grMobilePhoneMain must match format 998XXXXXXXXX (12 digits, starts with 998)` |
| ПИНФЛ | `grPinfl PINFL must be exactly 14 digits` |
| Паспорт | `grDocPassData passport must match format AA1234567 (2 uppercase letters + 7 digits)` |
| ИНН | `grInn INN must be exactly 9 digits` |
| Длина строки | `<свойство> size must be between 0 and <N>` |
| Число | `<свойство> numeric value out of bounds (<I digits>.<F digits> expected)` |

В `eidos-stage` они собираются в сообщение
`GoldenRecord validation failed for source=<код>: <нарушение>; <нарушение>`.
