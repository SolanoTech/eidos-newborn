# Очередь конфликтов

**Консоль администратора → Очередь конфликтов** — рабочее место
дата-стюарда. Сюда попадают данные, которые платформа не смогла применить
автоматически. Понятия — [Незавершённые записи и конфликты](../concepts/conflicts.md).

## Обзор

Переключатель **Физлица / Юрлица** выбирает очередь. Плитки над списком:

| Плитка | Что считает |
|---|---|
| В очереди | Всего записей, ждущих решения |
| Grey-zone | Конфликты при равном доверии источников |
| Unknown source | Данные от источников, которых нет в ядре |

Число рядом с пунктом меню — размер очереди физлиц.

В списке — **20 последних** записей, новые сверху. Для каждой:

- ФИО клиента или название мерчанта и имена расходящихся полей;
- для конфликта — начало идентификатора Золотой записи; для неизвестного
  источника — его код;
- тип: `grey-zone` или `unknown source`;
- сколько времени запись ждёт;
- кнопка **Разрешить**.

## Разобрать конфликт при равном доверии

1. Нажмите **Разрешить**. Откроется окно сравнения.
2. Для каждого расходящегося поля слева показано **текущее значение** Золотой
   записи, его источник и доверие, справа — **входящее значение** и источник,
   который его прислал.
3. Примите решение:

| Кнопка | Что произойдёт |
|---|---|
| **Оставить текущие** | Запись не меняется, конфликт закрывается |
| **Принять входящие** | Входящие значения переносятся в запись и закрепляются за источником, который их прислал; версия записи растёт |
| **Отклонить запись** | Входящие данные отбрасываются, конфликт закрывается |
| **Отложить** | Окно закрывается, конфликт остаётся в очереди |

!!! warning "«Принять входящие» переносит все расхождения"
    Переносятся все непустые входящие значения, которые отличаются от текущих,
    — в том числе в полях, принадлежащих источникам с более высоким доверием.
    Окно показывает их все: просмотрите список до конца. Частично принять
    карточку нельзя. Если подходит только часть значений, оставьте текущие
    и попросите источник исправить данные.

Решения необратимы. Кто принял решение, в текущей версии не записывается.

## Разобрать данные от неизвестного источника

Окно показывает пояснение и до 12 полей входящей карточки. Доступно только
**Отклонить запись**.

Такие записи появляются, когда источник есть в реестре и передаёт данные,
но не добавлен в таблицу источников ядра. Порядок действий:

1. Попросите администратора платформы зарегистрировать источник в ядре — см.
   [Регистрация источника](../sources/registration.md#регистрация-в-ядре).
2. Попросите источник отправить данные повторно.
3. Отклоните записи из очереди.

## Как выбирать решение

| Ситуация | Решение |
|---|---|
| Входящее значение — исправление ошибки, текущее устарело | Принять входящие |
| Входящее значение ошибочно или хуже текущего | Оставить текущие |
| Расходятся только пустые значения: один источник не прислал поле | Оставить текущие, если текущее значение заполнено |
| Непонятно, какое значение верное | Отложить и уточнить у владельцев источников |
| Конфликты одной и той же пары источников повторяются массово | Сообщите администратору: стоит развести уровни доверия |

Если очередь растёт быстрее, чем её удаётся разбирать, проблема почти всегда
в настройке источников, а не в данных: см.
[Как разбирать](../concepts/conflicts.md#как-разбирать).
