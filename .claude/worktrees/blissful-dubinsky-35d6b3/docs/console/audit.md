# Аудит-лог

**Консоль администратора → Аудит-лог** — журнал действий пользователей
консолей.

## Что записывается

В текущей версии в журнал попадают только операции с согласиями, выполненные
из консолей:

| Действие | Запись |
|---|---|
| Выдача согласия в карточке «Customer 360» | «Выдано согласие `<код типа>`», клиент |
| Отзыв согласия | «Отозвано согласие», идентификатор согласия |

Для каждой записи хранятся пользователь (логин Keycloak), действие,
подробности и время.

!!! warning "Не всё попадает в журнал"
    Подзаголовок экрана говорит о «всех действиях администраторов». На деле
    не записываются операции, которые консоль выполняет через Gravitee:
    создание и изменение источников, правка контрактов, разбор конфликтов,
    настройка Kafka. Вход и выход пользователей журнал тоже не фиксирует —
    события входа хранит Keycloak, если их сбор включён в настройках realm.

## Просмотр и выгрузка

- Журнал показывает **100 последних** записей, новые сверху.
- **Экспорт CSV** выгружает показанные записи с колонками `time`, `actor`,
  `action`, `details`.
- Через API можно получить до 500 последних записей:
  `GET /api/v1/admin/audit?limit=500` — см. [API eidos-cdi-ui-backend](../reference/api/ui-backend.md).

Записи журнала нельзя изменить или удалить через консоль и API.
