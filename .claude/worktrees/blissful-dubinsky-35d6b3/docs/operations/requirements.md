# Требования

## Ресурсы

| Окружение | ЦП | Память | Диск |
|---|---|---|---|
| Стенд на рабочей машине, без Gravitee | 4 ядра | 8 ГБ для Docker | 20 ГБ |
| Стенд с Gravitee APIM | 4–6 ядер | 12–16 ГБ для Docker | 30 ГБ |
| Сервер | По результатам [нагрузочной проверки](performance.md) | | |

Основные потребители памяти: пять Java-сервисов, Keycloak, Redpanda и — в
стеке Gravitee — Elasticsearch. Ограничения памяти для контейнеров в
`docker-compose.yml` не заданы; на сервере задайте их явно — см.
[Стенд и продуктив](production.md).

Место на диске занимают образы (JDK, Node.js, nginx, инфраструктура — несколько
гигабайт), тома PostgreSQL и MongoDB. Растут они так:

- **MongoDB** — каждая принятая шлюзом карточка сохраняется как сырьё, без
  срока хранения;
- **PostgreSQL** — Золотые записи, по строке происхождения на каждое поле,
  копия записи в архиве на каждое изменение.

## Программное обеспечение

| Компонент | Версия | Где задаётся |
|---|---|---|
| Docker Engine | 24 или новее | — |
| Docker Compose | v2 | — |
| Python | 3.10 или новее | Скрипт настройки Gravitee, скрипты `loadtest` |
| Git | любая актуальная | — |

Сборка образов идёт внутри Docker: JDK, Maven и Node.js на хосте не нужны.

Для разработки и сборки из исходников без Docker нужны JDK 26 и Node.js 22 —
см. [Сборка и тесты](../development/build.md).

## Компоненты платформы

| Компонент | Версия на стенде | Назначение |
|---|---|---|
| Java (Eclipse Temurin) | 26 | Сервисы модуля |
| Spring Boot | 4.0.6 / 4.1.0 | Сервисы модуля |
| PostgreSQL | 16 | Золотые записи, реестр, согласия, настройки, Keycloak |
| MongoDB | 7 | Сырьё источников |
| Redpanda | 24.2.7 | Kafka-совместимый брокер |
| Keycloak | 26.0 | Вход в консоли |
| OpenBao | `latest` | Хранилище ключа шифрования ключей |
| Gravitee APIM | `latest` | Маршрутизация административных путей консолей |
| Elasticsearch | 8.16.1 | Аналитика Gravitee |
| nginx | 1.27 | Раздача консолей |
| Node.js | 22 | Сборка консолей |

Платформа рассчитана на любую реализацию Kafka API: Apache Kafka, Redpanda,
управляемые облачные сервисы — при условии, что брокер принимает соединения
без аутентификации (см. [Передача через Kafka](../sources/kafka.md)). Вместо
контейнеров PostgreSQL и MongoDB можно использовать внешние экземпляры тех же
основных версий. В PostgreSQL должно быть доступно расширение `pg_trgm`.

Образы OpenBao и Gravitee указаны с тегом `latest`. Для воспроизводимой
установки закрепите конкретные версии — см. [Стенд и продуктив](production.md).

## Сеть
