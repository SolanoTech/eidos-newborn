# Поиск и карточка клиента

**Консоль администратора → Поиск Golden Records** — поиск физлица по
реквизитам и просмотр его Золотой записи.

## Найти клиента

Заполните одно или несколько полей и нажмите **Найти клиента** (или
<kbd>Enter</kbd>):

| Поле | Как сравнивается |
|---|---|
| ПИНФЛ | Только целиком, 14 цифр. Нецифровые символы отбрасываются |
| Серия и № паспорта | По части номера; пробелы и регистр не важны |
| Фамилия, Имя, Отчество | По части значения, без учёта регистра |
| Телефон | По части номера; учитываются только цифры, `+998 90 …` можно вводить как есть |

Заполненные условия объединяются по «И». Если не заполнено ничего, поиск
покажет первые записи базы.

Над результатами — число совпадений. Консоль показывает **первые 20**
результатов; если совпадений больше, уточните условия. Пометка «точное
совпадение» у результатов означает лишь то, что запись удовлетворяет условиям,
а не точное совпадение всех реквизитов.

**Сбросить** очищает поля и результаты.

## Карточка клиента

Щелчок по результату открывает карточку:

- **Шапка** — ФИО, начало идентификатора записи (`gr_client_id`), чип с номером
  версии.
- **Поля профиля** — телефон, ПИНФЛ, дата рождения, пол, паспорт и дата его
  выдачи, место рождения, гражданство.
- **Происхождение полей** — для каждого поля записи: источник, давший текущее
  значение, и его уровень доверия. Имена полей показаны в форме свойств
  (`grMobilePhoneMain`), см. [Модель данных](../concepts/data-model.md#три-формы-имени-поля).
- **Экспорт** — скачивает JSON с записью и происхождением полей.

Карточка показывает основные поля профиля. Все поля записи, включая адреса,
есть в экспорте и в API.

## Как проверить профиль

- **Откуда значение?** Посмотрите на «Происхождение полей»: поле принадлежит
  источнику с наибольшим доверием из тех, кто прислал отличающееся значение.
  См. [Слияние и происхождение](../concepts/merge.md).
- **Почему не обновилось?** Если поле принадлежит источнику с большим или
  равным доверием, менее надёжный источник его не изменит, а тот же источник —
  не перезапишет своё же значение.
- **Как менялась запись?** Номер версии показывает число изменений. Истории
  изменений в консоли нет; архив состояний доступен администратору базы данных
  в таблице `golden_record_archive`.
- **Где ещё известен клиент?** Связанные идентификаторы в системах-источниках
  показывает карточка «Customer 360» во [фронт-офисе](front-office.md).
