# Чек-лист перед продуктивом

Пройдите этот список перед загрузкой реальных данных. Пояснения — по ссылкам.

## Секреты

- [ ] `ADMIN_TOKEN` — длинная случайная строка, не значение по умолчанию.
      Совпадает в `.env` и в политике Gravitee. → [Конфигурация](../operations/configuration.md)
- [ ] Пароль PostgreSQL сменён, сервисы получают его из переменных; лучше —
      отдельный пользователь на каждый сервис. → [Стенд и продуктив](../operations/production.md#файл-переопределений), [Базы данных](../operations/databases.md#пользователи-и-права)
- [ ] Токен OpenBao для ядра — не корневой, с политикой только на шифрование
      и расшифровку KEK. → [OpenBao](../operations/openbao.md#сервер-постоянное-хранилище)
- [ ] Учётные данные администратора Keycloak сменены; учебный пользователь
      `admin` удалён из realm `eidos`; секрет клиента `eidos-m2m` сменён. → [Keycloak](../operations/keycloak.md)
- [ ] Пароль администратора Gravitee сменён.
- [ ] Токены источников сгенерированы заново и переданы по защищённым
      каналам; учебные источники удалены или их токены сменены.
- [ ] `.env` закрыт от чтения посторонними (`chmod 600`) и не попадает в
      репозитории и резервные копии без шифрования.

## Сеть

- [ ] Наружу опубликованы только `eidos-gateway`, консоли и Keycloak — через
      обратный прокси с TLS. → [Периметр](perimeter.md)
- [ ] Порты `eidos-core`, `eidos-stage`, `eidos-consents`,
      `eidos-cdi-ui-backend`, баз, Kafka, OpenBao и Gravitee на хосте не
      опубликованы.
- [ ] Путь `/internal/**` шлюза закрыт на обратном прокси.
- [ ] Ограничение частоты запросов к шлюзу настроено на обратном прокси.
- [ ] Брокер Kafka доступен только из внутренней сети.

## Компоненты

- [ ] Keycloak работает в производственном режиме, `sslRequired` — `external`,
      адреса возврата клиента `eidos-console` — только реальные адреса консолей.
- [ ] Консоли собраны с адресом Keycloak сервера. → [Адрес Keycloak в консолях](../operations/production.md#адрес-keycloak-в-консолях)
- [ ] OpenBao работает с постоянным хранилищем; процедура распечатывания
      описана и проверена.
- [ ] Версии образов OpenBao и Gravitee закреплены.
- [ ] В realm `eidos` только сотрудники, которым нужна роль `ADMIN`.

## Данные

- [ ] Резервное копирование PostgreSQL, MongoDB и OpenBao настроено, восстановление
      проверено. → [Резервное копирование](../operations/backup.md)
- [ ] Диски с базами и резервными копиями зашифрованы.
- [ ] Срок хранения сырья, топиков Kafka и журналов определён и настроен. → [Персональные данные](personal-data.md#минимизация)
- [ ] Определён ответственный за обработку персональных данных и порядок
      исполнения запросов клиентов. → [Персональные данные](personal-data.md#удалить-данные-клиента)

## Эксплуатация

- [ ] Проверки `/health`, размер очереди конфликтов, отклонения и отставание
      Kafka отслеживаются. → [Мониторинг](../operations/monitoring.md)
- [ ] Журналы собираются централизованно, срок хранения ограничен.
- [ ] Команда знает об ограничениях текущей версии. → [Статус и ограничения](../intro/status.md)
