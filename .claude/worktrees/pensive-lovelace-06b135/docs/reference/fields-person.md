# Поля Золотой записи физлица

Описание записи — класс `GoldenRecordDto` библиотеки `shared-library`. Таблица
построена из него скриптом `tools/docs/generate_field_reference.py`.

- **Поле контракта** — имя, которое указывается целевым полем в
  дата-контракте.
- **Свойство в API** — имя поля в ответах API ядра, в происхождении полей и в
  конфликтах.
- **Обяз.** — без значения карточка отклоняется.
- **Ограничения** — проверяются при каждой карточке в `eidos-stage`.
- **Тип правила** — тип, который нужно выбрать для правила контракта.

Даты в ответах API — `yyyy-MM-dd`, пол — `M` или `F`. Понятия —
[Модель данных](../concepts/data-model.md).

## Служебные свойства

В ответах API ядра, кроме полей записи, есть служебные свойства. Источник их
не передаёт.

| Свойство | Значение | Описание |
|---|---|---|
| `grClientId` | строка `GR_<uuid>` | Идентификатор Золотой записи |
| `version` | целое | Номер версии, с 0; растёт при каждом изменении данных |
| `createdAt` | дата и время | Создание записи, по часам сервера |
| `updatedAt` | дата и время | Последнее изменение строки записи |
| `pdConsentActive` | логическое или `null` | Действует ли согласие на обработку персональных данных; `null` — ядро ещё не сверялось |
| `pdConsentValidTo` | дата или `null` | Последний день действия согласия |
| `pdConsentCheckedAt` | дата и время или `null` | Когда ядро сверялось с сервисом согласий |
| `pdBiIdentity`, `pdBiIdentityDoc`, `pdBiPinfl` | строка, 64 шестнадцатеричных символа | Слепой индекс |
| `pdBiKeyVersion` | целое | Версия ключа слепого индекса |

Свойства `pd*` — внутренние, их состав может измениться. Не используйте их в
интеграции.
