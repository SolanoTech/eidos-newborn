# Проверка согласия

Перед обработкой персональных данных клиента — рассылкой, профилированием,
передачей партнёру — система-потребитель проверяет, действует ли у клиента
согласие нужного типа. Модель согласий — [Согласия](../concepts/consents.md).

## Проверить одно согласие

```http
GET /api/v1/consents/active/{clientId}?type=MARKETING_SMS
X-Access-Token: <токен>
```

- `clientId` — идентификатор Золотой записи физлица в любой форме: `GR_<uuid>`
  или `<uuid>`.
- `type` — **имя** типа: `PERSONAL_DATA`, `BIO`, `MARKETING_SMS`,
  `MARKETING_PUSH`, `MARKETING_EMAIL`, `PROFILING`, `THIRD_PARTY`.

| Ответ | Решение |
|---|---|
| `200` и согласие в теле | Согласие действует сегодня — обработка разрешена |
| `404` `No active consent of type … for client …` | Действующего согласия нет: не выдавалось, истекло или отозвано |
| `400` `Invalid value for parameter 'type': …` | Неверное имя типа — ошибка интеграции |
| `5xx`, таймаут | Состояние неизвестно |

Ответ `200`:

```json
{
  "id": "0b8f3c1d-6a2e-4f7b-9d61-3c9e2a7b5f40",
  "client_uuid": "5f0c2b1e-8a4d-4c55-9a8e-2b7d4f1c9e10",
  "start_date": "2026-10-01",
  "end_date": "2027-09-30",
  "type": "mk_sms",
  "source": "bank-1"
}
```

## Проверить все типы сразу

```http
GET /api/v1/consents/client/{clientId}
X-Access-Token: <токен>
```

Ответ — по одной строке на каждый тип: последнее согласие и признак `active`
на сегодня. Удобно для карточки клиента и для массовых проверок; формат —
[Передача согласий](../sources/consents.md#прочитать-согласия-клиента).

## Рекомендации

- **Проверяйте непосредственно перед обработкой.** Отзыв действует с момента
  отзыва, а событие о нём может не прийти.
- **Не принимайте отсутствие ответа за согласие.** При ошибке или таймауте
  считайте, что согласия нет, и повторите проверку позже.
- **Кешируйте коротко.** Если кешируете результат, ограничьте срок жизни
  кеша — например, минутами, а не днями — и сбрасывайте его по событиям
  о согласиях.
- **Не используйте поле `pdConsentActive` Золотой записи** для решений: оно
  отражает только согласие на обработку персональных данных, обновляется по
  событиям и может отставать.
