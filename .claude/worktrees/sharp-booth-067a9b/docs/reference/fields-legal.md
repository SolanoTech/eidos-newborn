# Поля Золотой записи юрлица

Описание записи — класс `LegalEntityGoldenRecordDto` библиотеки
`shared-library`. Таблица построена из него скриптом
`tools/docs/generate_field_reference.py`. Значение колонок — как в
[справочнике полей физлица](fields-person.md).

Описания полей даны по названиям реестровых показателей. Справочники кодов —
ОКЭД, СООГУ, КФС, СОАТО, коды состояний и режимов налогообложения —
определяются источником данных.

--8<-- "docs/reference/_generated/legal-table.md"

## Учредитель

Элемент массива `GR_Founders`. Структура предварительная: состав подобран по
типовому набору реестра и может быть уточнён по контрактам источников. Ключи
элемента в данных источника должны совпадать с ключами ниже, остальные ключи
отбрасываются.

--8<-- "docs/reference/_generated/founder-table.md"

## Служебные свойства

| Свойство | Значение | Описание |
|---|---|---|
| `grLegalEntityId` | строка `LE_<uuid>` | Идентификатор Золотой записи юрлица |
| `version` | целое | Номер версии, с 0 |
| `createdAt`, `updatedAt` | дата и время | Создание и последнее изменение |
| `nameNormalized` | строка | Нормализованное название для нечёткого поиска — см. [Нечёткий поиск мерчанта](../consumers/search.md#нечёткий-поиск-мерчанта) |
