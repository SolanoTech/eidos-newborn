# Поиск и карточка юрлица

**Консоль администратора → Поиск юрлиц** — поиск мерчанта и просмотр его
Золотой записи.

## Найти мерчанта

Выберите режим:

- **По ИНН · точный** — введите 9 цифр ИНН. Результат — одна запись или
  сообщение «Юрлицо с таким ИНН не найдено».
- **По названию · неточный** — введите название или его часть в любом
  написании: «Оазис Маркет», «OAZIS», «ООО "Оазис"». Результаты отсортированы по
  сходству, показываются первые 20.

Поиск по названию не обращает внимания на регистр, кавычки, кириллицу или
латиницу и организационно-правовую форму. Если ничего не найдено, попробуйте
часть названия без формы собственности. Как это работает —
[Нечёткий поиск мерчанта](../consumers/search.md#нечёткий-поиск-мерчанта).

У каждого результата — ИНН, организационно-правовая форма и статус:
«действует», «не действует» или «банкрот».

## Карточка юрлица

| Блок | Содержимое |
|---|---|
| Шапка | Наименование, статус, номер версии записи |
| Реквизиты | Полное и краткое наименование, ОПФ, дата и номер регистрации, орган регистрации, уставный фонд, ОКЭД |
| Адрес и контакты | Адрес, регион и район, телефоны, руководитель, число учредителей |
| Налоги и благонадёжность | Режим налогообложения, плательщик НДС и номер НДС, малый бизнес, рейтинг надёжности, скоринг |
| Учредители | Список учредителей с долями, если источник их передал |
| Происхождение полей | Источник и уровень доверия для каждого поля |
| Идентификаторы в системах | Номера мерчанта в системах-источниках; неактивные отмечены |

**Экспорт** скачивает карточку в JSON.

Те же данные в упрощённом виде показывает карточка «Merchant 360» во
[фронт-офисе](front-office.md).
