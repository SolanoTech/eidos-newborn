# shared-library

Общий контракт данных платформы. Описывает, как выглядит Золотая запись, и
подключается ко всем модулям, которые её создают, передают или читают.

## Что внутри

**`GoldenRecordDto`** — Золотая запись физического лица: имя, документы,
гражданство, адреса регистрации и контакты. Поля размечены правилами проверки:
ПИНФЛ из четырнадцати цифр, телефон в формате страны, серия и номер паспорта,
обязательность.

**`LegalEntityGoldenRecordDto`** — Золотая запись юридического лица: ИНН,
наименование и бренд, организационно-правовая форма, вид деятельности,
регистрационные сведения, адреса, контакты, руководитель и учредители.

**`RecordFieldCatalog`** — машиночитаемое описание полей любой из записей: имя,
тип, обязательность. Из него строятся конструктор дата-контрактов в консоли
администратора и приведение типов при трансформации.

**`Gender`** — пол с разбором принятых в источниках обозначений.

Имена полей в JSON единые для обеих записей и не зависят от того, как поле
называется в базе или у источника.

## Установка

Библиотека не разворачивается отдельно — она подключается к модулям. Перед
сборкой любого сервиса её нужно установить в локальный репозиторий:

```bash
mvn -f shared-library/pom.xml clean install
```

В Docker это делается само: образы сервисов собираются из корня проекта и
включают библиотеку в сборку.

Тесты:

```bash
cd shared-library && ./mvnw test
```

## Конфигурация

Собственной конфигурации у библиотеки нет.

## Эндпоинты

Библиотека не предоставляет сетевых интерфейсов.

Состав полей Золотой записи доступен через
`GET /internal/api/v1/golden-record-fields` в eidos-stage — он отдаёт каталог
полей для настройки маппинга источников.
