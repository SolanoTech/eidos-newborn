# eidos-cdi-ui-backend

Backend-for-frontend консолей: обслуживает то, что нужно интерфейсу, но не
принадлежит ни одному доменному сервису, — сводные показатели, журнал действий
оператора и работу с согласиями из карточки клиента.

## Что делает

**Сводка для дашборда** — показатели платформы, собранные из нескольких сервисов
в один ответ, чтобы консоль не делала это сама.

**Журнал действий.** Операции, выполненные операторами через консоль, пишутся с
указанием кто, что и с каким результатом.

**Согласия клиента** в карточке: сводка по типам, выдача и отзыв. Проксирует
сервис согласий и записывает каждую операцию в журнал.

Большая часть обращений консолей идёт мимо этого сервиса: реестр источников,
дата-контракты, Золотые записи, конфликты и конфигурация потребителей
маршрутизируются напрямую через API-шлюз. Здесь остаётся только то, что требует
сведения данных или аудита.

**Доступ** — по токену Keycloak. Административные пути закрыты ролью.

## Установка

```bash
docker compose up -d eidos-cdi-ui-backend
```

Поднимет заодно PostgreSQL и сервисы, к которым обращается. Отдельно, без
приложения:

```bash
docker compose up -d postgres keycloak
```

Локально из исходников (нужен JDK 26):

```bash
cd eidos-cdi-ui-backend && ./mvnw spring-boot:run
```

Тесты:

```bash
cd eidos-cdi-ui-backend && ./mvnw test
```

## Конфигурация

`src/main/resources/application.properties`; в контейнере переопределяется
переменными окружения.

| Ключ | Назначение |
|---|---|
| `server.port` | порт сервиса, по умолчанию `8083` |
| `spring.datasource.url` | собственная база: журнал действий |
| `spring.datasource.username` / `.password` | доступ к базе |
| `eidos.core.base-url` | адрес eidos-core |
| `eidos.stage.base-url` | адрес eidos-stage |
| `eidos.stage.admin-token` | токен административного API stage |
| `eidos.gateway.base-url` | адрес eidos-gateway |
| `eidos.gateway.admin-token` | токен административного API gateway |
| `eidos.consents.base-url` | адрес сервиса согласий |
| `spring.security.oauth2.resourceserver.jwt.jwk-set-uri` | ключи проверки токенов Keycloak |

На хосте сервис отдан на порт **8093**.

## Эндпоинты

Требуют токен Keycloak; пути под `/api/v1/admin` — ещё и соответствующую роль.

| Метод | Путь | Назначение |
|---|---|---|
| `GET` | `/api/v1/admin/dashboard` | сводные показатели платформы |
| `GET` | `/api/v1/admin/audit` | журнал действий операторов |
| `GET` | `/api/v1/admin/consents/{clientUuid}` | согласия клиента по всем типам |
| `POST` | `/api/v1/admin/consents/grant` | выдать согласие; тело `{"clientUuid": "...", "type": "pd"}` |
| `POST` | `/api/v1/admin/consents/{consentId}/revoke` | отозвать согласие |
| `GET` | `/health` | проба живости |

Выдача и отзыв согласия попадают в журнал действий.
